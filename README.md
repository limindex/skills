# LimIndex skills

LimIndex(개인 개발 브랜드)가 만드는 AI 코딩 도구용 스킬·플러그인 모음(Claude Code marketplace).

| plugin | 설명 |
|---|---|
| [white-security](https://github.com/limindex/white-security) | 바이브 코딩 보안 점검 — 코드를 쓸 때 흔한 보안 실수를 막고, 요청하면 읽기 전용으로 검토 |

## 설치 (Claude Code)

```
/plugin marketplace add limindex/skills
/plugin install white-security@limindex
```

업데이트: `/plugin marketplace update limindex` (서드파티 marketplace 는 자동 업데이트가 기본으로 꺼져 있음)
